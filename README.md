# Crypto_trading_bot
A simplified Python trading bot for Binance Futures Testnet supporting market, limit, and stop-limit orders with CLI input validation, logging, and error handling using the official Binance API.

---

##  Features

- Binance **Futures Testnet (USDT-M)** support  
- Place **Market**, **Limit**, and **Stop-Limit** orders  
- Supports **BUY** and **SELL** order sides  
- Command-Line Interface (CLI) for user interaction  
- Input validation and structured output  
- API request/response logging  
- Robust error handling using Binance exceptions  
- Modular and reusable class-based design  

---

## Tech Stack

- **Language:** Python 3  
- **API:** Binance Futures REST API  
- **Library:** `python-binance`  
- **Logging:** Python `logging` module  

---

##  Prerequisites

1. Python 3.8+
2. Binance Futures Testnet Account  
   - Register at: https://testnet.binancefuture.com
3. Generate API Key & Secret from the Testnet dashboard
